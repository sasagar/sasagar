# `output` branch

Generated artifacts only — **do not edit by hand.**

The SVGs here are regenerated daily by
[`.github/workflows/metrics.yml`](https://github.com/sasagar/sasagar/blob/main/.github/workflows/metrics.yml)
on the `main` branch using [lowlighter/metrics](https://github.com/lowlighter/metrics),
and are embedded in the profile README.

| File | Content |
| --- | --- |
| `metrics.overview.svg` | Header, activity, community stats, repositories, isometric contribution calendar |
| `metrics.languages.svg` | Most used languages, issue / pull request status |
| `metrics.contributions.svg` | Notable contributions, featured repositories |
| `metrics.starred.svg` | Recently starred repositories |

---

This branch previously also held `profile-summary-card-output/`, generated by
[github-profile-summary-cards](https://github.com/vn7n24fzkq/github-profile-summary-cards),
along with a copy of that workflow and of the profile README.
Those were retired when the profile moved to *metrics*; see this branch's git history if you need them.
